LAVA ISLES — an English game for Gur

HOW TO START
  Double-click Play.bat (needs Python). It opens the game in the browser at http://localhost:8123.

WHAT GUR DOES
  Press PLAY -> a slot machine picks a random game -> 5 games in a row -> a treasure chest.
  Gems fix castles, eggs + items hatch lava animals, beat the dragons to open the next bridge.
  Each game has its own level 1-5 that goes up when he plays it well (and down if it is too hard).
    ABC           first letters and sounds ("c is for cat")
    Potions       read the recipe words, find the pictures
    Letters       connect letters on a grid to spell words
    Sentences     fill the missing word / put words in order
    Write         hear a word, type it
    Memory        match each word to its picture
    Time Machine  pick the right verb: jumped / jumps / will jump
    When?         read a sentence: Past, Present or Future?
    Word Bridge   build the sentence word by word across the lava     
  Hatch      combine two things; the clue book is simple English sentences to read.
             Some things are rare (sun, comet, rainbow, crystal, gold egg) and make rare animals.
  Decorate   buy things for the island and put them anywhere. A gift is a surprise.
  Castles    tap a fixed castle -> Paint: roof, walls and flag colours (colour words).
  Dragons    fire timer + hearts: a wrong or too-slow answer burns the hero. You can lose and try again.
  Map        drag to look around, mouse wheel to zoom. Tap the whale / boat / balloon for gems.

PARENTS
  Gear icon (top right) -> hold the button for 2 seconds.
  Shows words learned, words that need practice, accuracy per skill, time played,
  and every game with its level (tap one to play just that game).
  Settings: Hebrew hints on/off, voice speed, music, erase progress.
  Progress is saved in this browser automatically.
